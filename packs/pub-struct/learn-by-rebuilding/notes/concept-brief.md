## The loop

1. Pick one idea everyone uses but few understand.
2. Rebuild it from scratch, as small as possible.
3. Explain it in public, out loud, step by step.
4. Ship the code so others can run it.
5. Name what you learned.
6. Repeat with the next idea.

## Four weekends

- [ ] **Week 1: pick.** Write down why ${input:concept} is the one, what you can already
  say about it, and the three questions you cannot answer yet.
- [ ] **Week 2: rebuild.** The Builder and you write the toy version, step by step, and
  the Student runs every step. Ugly is fine; working is the point.
- [ ] **Week 3: explain.** Record yourself explaining it from a blank screen, with the
  Lecture script beside you. No slides.
- [ ] **Week 4: ship.** Publish the repository and the recording together, then the post
  about the part that surprised you.

## Rules for the build

- No library that hides the part being learned.
- Every step runs, and prints or shows something.
- Every file reads in one sitting.
